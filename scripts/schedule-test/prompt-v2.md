# スケジュール抽出プロンプト v2（テスト用）

v1（prompt.md）からの変更点:
1. 【内部行事の除外】デイサービス等の施設利用者向け内部行事は抽出しない
2. 【週次配信トピック】毎週のLINE配信で取り上げる価値がありそうなイベントに weekly_topic フラグを付ける

---

添付（Readした）PDFから、地域カレンダーに登録すべき「日付が確定しているイベント」を抽出してください。

## パラメータ（実行時に指定）
- 基準日（発行日）: {ISSUE_DATE}
- 本日: {TODAY}
- このPDFの発行元種別: {JICHIKAI ? "自治会関連" : "自治会以外（地域のお知らせ）"}

## 抽出ルール
- 開催日が特定できるものだけ抽出（「毎週」「随時」「未定」は除外。ただし連続イベントは下記参照）
- 年が書かれていない日付は、基準日にもっとも日付が近くなる年で解釈（基準日より前になっても翌年へ繰り上げない）
- 【過去除外】実際の開催日をそのまま使う。開催日が {TODAY}（本日）より前になる予定は出力に含めない（当日は含める）。日付を本日や別日に書き換えない
- 【募集・締切】
  - 自治会関連の場合: 申込締切など忘れると困る日付は「〆切」を含むタイトルで抽出してよい
  - 自治会以外の場合: 募集・申込・〆切/締切は抽出しない（実際に開催されるイベントの開催日のみ）
- 過去の報告（開催済みの報告）は除外
- 【内部行事の除外】一般の地域住民が参加できないものは抽出しない。
  - デイサービス・介護施設・保育園・学校などの「利用者/在籍者向け」の行事予定（お誕生日会、施設内の教室・作品作り・レクリエーション等）
  - 会員・在籍者のみ対象の定例活動（一般参加の案内が無いもの）
  - 判断基準: 「誰でも参加できる」「申込先がある」「地域の方へ」など一般向けの案内があれば抽出。施設内の月間予定表として載っているだけなら除外
- 【種別 category】
  - "reserve": 予約・事前申込が必要（要予約/申込先/地区センター講座など対象限定）
  - "recurring": 継続・定期開催。「毎週/隔週/毎月/定期/全N回/連続」、タイトルの「①②③/(2)/第N回」、習い事・教室・講座・サロン・クラブ等
  - "open": 申込不要で当日自由参加（お祭り・サロン等）
  - どれでもなければ null
- 【連続の集約】recurring は日付ごとに分けず1件。event_date は基準日以降で最も近い開催日、title/timeに「毎週◯曜」等
- organizer は主催団体（自治会/子ども会/学校/ケアプラザ等）。不明なら null

## 週次配信トピック（weekly_topic）
自治会の公式LINEでは毎週「今週のお知らせ」を配信する。そこで**紹介する価値がありそうなイベント**に weekly_topic: true を付ける。
- true にする目安: 幅広い住民が興味を持ち、参加のハードルが低いもの。お祭り・芸術祭・発表会・講演会・体験講座（初めての人向け）・季節行事・防災訓練・地域の集まり（だれでも参加可）など。年に数回しかない「目玉」感があるもの
- false にする目安: 毎週/毎月の定例教室・サロン・クラブ活動、対象が限定的なもの（介護者のみ等）、専門的で一般向けでないもの
- topic_reason に判断理由を15字以内で書く（例: 「年1回の芸術祭」「定例サロン」）

## 出力（JSONのみ）
```json
{"events":[
  {"title":"20字以内","event_date":"YYYY-MM-DD","event_time":"10:00-12:00 or null","event_location":"場所 or null","organizer":"主催団体 or null","category":"reserve|recurring|open|null","has_details":true,"weekly_topic":true,"topic_reason":"15字以内"}
]}
```
該当なしは {"events":[]}。
