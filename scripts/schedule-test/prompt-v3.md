# スケジュール抽出プロンプト v3（テスト用）

v2（prompt-v2.md）からの変更点:
1. 【名称は原文のまま】タイトルはPDFに書かれた名称をそのまま使う。複数の記事を組み合わせて新しい名前を作らない
2. 【根拠の引用 source_text】各イベントに、日付と名称が書かれている原文の一節を付ける（原文に無い語が入ったものを機械的に弾くため）
3. 【1枠に複数日付】同じ枠（囲み）に複数の開催日が並ぶものは recurring として1件にまとめる
補足: 内部行事の除外はセクション見出しを判断材料にする。一般向けの案内があるものは除外しない。だれでも参加可のものは weekly_topic を true 寄りに判定

---

添付（Readした）PDFから、地域カレンダーに登録すべき「日付が確定しているイベント」を抽出してください。

## パラメータ（実行時に指定）
- 基準日（発行日）: {ISSUE_DATE}
- 本日: {TODAY}
- このPDFの発行元種別: {JICHIKAI ? "自治会関連" : "自治会以外（地域のお知らせ）"}

## 抽出ルール
- 開催日が特定できるものだけ抽出（「毎週」「随時」「未定」は除外。ただし連続イベントは下記参照）
- 年が書かれていない日付は、基準日にもっとも日付が近くなる年で解釈（基準日より前になっても翌年へ繰り上げない）
- 【過去除外】実際の開催日をそのまま使う。開催日が {TODAY}（本日）より前になる予定は出力に含めない（当日は含める）。日付を本日や別日に書き換えない
- 【募集・締切】
  - 自治会関連の場合: 申込締切など忘れると困る日付は「〆切」を含むタイトルで抽出してよい
  - 自治会以外の場合: 募集・申込・〆切/締切は抽出しない（実際に開催されるイベントの開催日のみ）
- 過去の報告（開催済みの報告）は除外
- 【内部行事の除外】一般の地域住民が参加できないものは抽出しない
  - チラシが「〜からのご案内」等のセクションに分かれている場合、セクション見出しを判断材料にする。「通所介護（デイサービス）」「保育園」「学校」など施設の利用者・在籍者向けセクションにある月間予定（お誕生日会、体操教室、作品作り等）は除外
  - 対象が「ご家族の介護をしている方」「子育て中の方」「65歳以上」など属性で絞られていても、一般に開かれた案内（申込先がある、「お気軽にご参加ください」等）があれば抽出する。除外するのは「その施設の利用者しか参加できないもの」だけ
- 【名称は原文のまま】title はPDFに書かれているイベント名をそのまま使う（20字を超える場合のみ末尾を省く）。別の記事の語を混ぜたり、内容から名前を作ったりしない。名前が無い場合のみ内容を要約した名前にする
- 【1枠に複数日付】同じ囲み・同じ見出しの中に開催日が複数並ぶもの（例: 9/25(金)・10/23(金)）は、日付ごとに分けず recurring として1件にする。event_date は基準日以降で最も近い開催日、他の日付は event_time か title に補記する（例: "13:30-15:30（10/23も）"）
- 【種別 category】
  - "reserve": 予約・事前申込が必要（要予約/申込先/地区センター講座など対象限定）
  - "recurring": 継続・定期開催。「毎週/隔週/毎月/定期/全N回/連続」、タイトルの「①②③/(2)/第N回」、習い事・教室・講座・サロン・クラブ等、および上記の複数日付
  - "open": 申込不要で当日自由参加（お祭り・サロン等）
  - どれでもなければ null
- organizer は主催団体（自治会/子ども会/学校/ケアプラザ等）。セクション見出しにある発行部署（例: 地域包括支援センター）も主催として使ってよい。不明なら null

## 根拠の引用（source_text）
各イベントに、そのイベント名と開催日が書かれている原文の一節を40字以内でそのまま書き写す（要約・言い換え禁止）。title の語は source_text に含まれていなければならない。原文に見つからないイベントは出力しない。

## 週次配信トピック（weekly_topic）
自治会の公式LINEでは毎週「今週のお知らせ」を配信する。そこで紹介する価値がありそうなイベントに weekly_topic: true を付ける。
- true にする目安: 幅広い住民が興味を持ち、参加のハードルが低いもの。お祭り・芸術祭・発表会・講演会・体験講座（初めての人向け）・季節行事・防災訓練など。年に数回しかない「目玉」感があるもの。「だれでも」「どなたでも」参加できると書かれているものは true 寄りに判定
- false にする目安: 毎週/毎月の定例教室・サロン・クラブ活動、専門的で一般向けでないもの
- topic_reason に判断理由を15字以内で書く（例: 「年1回の芸術祭」「定例サロン」）

## 出力（JSONのみ）
```json
{"events":[
  {"title":"原文どおり20字以内","event_date":"YYYY-MM-DD","event_time":"10:00-12:00 or null","event_location":"場所 or null","organizer":"主催団体 or null","category":"reserve|recurring|open|null","has_details":true,"weekly_topic":true,"topic_reason":"15字以内","source_text":"原文の一節40字以内"}
]}
```
該当なしは {"events":[]}。
