## 1. クラウドソーシング（LINE を使った仕組みづくりの需要と供給）

**要点**
- 依頼の中心は**集客（マーケティング）**。Lステップ・エルメの構築、リッチメニュー、画像が大半。業務システム寄り（Bot・GAS・LIFF）は数十〜200件の規模。
- 「出欠」「会員管理」「顧客管理」という言葉の依頼はほぼゼロ。メンバー型の組織（教室・管理組合・団体）は**クラウドソーシングでは発注しない**層と見られる（推測）→ 営業の経路は別に要る。
- 相場: **構築は3万円前後、保守は月1万円前後**が基準。構築の出品は1,500件超で値崩れ。月額保守の出品は売れていない。
- 一方で LINE公式アカウント・Lステップ・エルメといった**ツール本体には月額で払っている** → 「保守」ではなく「**ツールとして月額で使ってもらう**」形が勝ち筋（推測）。
- 防災の会の**安否確認Bot が30〜40万円**で発注された例 → 「防災・安否確認」の切り口なら会員組織にも予算がつく。
- 「AI（ChatGPT・Claude・Dify）× LINE Bot」の依頼が増えている。AI の自動返信は月額サービスの付加価値になる。

**開けなかったところ**: クラウドワークスの検索ページ（3種類のURLとも表示できず。個別案件1件だけ開けた）、タイムチケット（403）。

### 事業への示唆（推測を含む）
1. **入口の価格**: 会員組織向けの月額サービスは、「構築3万円＋保守月1万円」より安く見えるか、ツール代込みで同じくらいに見える必要がある。目安は**月3,000〜10,000円**。
2. **受託より月額のツール**: 受託の構築は値崩れ。月額保守は単独では売れない。Lステップ・エルメのように「ツールとして月額で使ってもらう」。初期設定（3〜5万円）の入口は残すと乗り換えやすい。
3. **狙い目**: 案件数と予算があるのは医療・整骨院・歯科・美容の予約・会員証・リマインド。自分の強み（名簿・出欠・回覧・安否確認）が直接効くのは自治会・管理組合・教室・スポーツ団体・非営利だが、営業の経路は別に要る。
4. **AI 自動返信**を月額サービスの付加価値として付ける。
