## 1. クラウドソーシング（LINE を使った仕組みづくりの需要と供給）

**要点**
- 依頼の中心は**集客（マーケティング）**。Lステップ・エルメの構築、リッチメニュー、画像が大半。業務システム寄り（Bot・GAS・LIFF）は数十〜200件の規模。
- 「出欠」「会員管理」「顧客管理」という言葉の依頼はほぼゼロ。メンバー型の組織（教室・管理組合・団体）は**クラウドソーシングでは発注しない**層と見られる（推測）→ 営業の経路は別に要る。
- 相場: **構築は3万円前後、保守は月1万円前後**が基準。構築の出品は1,500件超で値崩れ。月額保守の出品は売れていない。
- 一方で LINE公式アカウント・Lステップ・エルメといった**ツール本体には月額で払っている** → 「保守」ではなく「**ツールとして月額で使ってもらう**」形が勝ち筋（推測）。
- 防災の会の**安否確認Bot が30〜40万円**で発注された例 → 「防災・安否確認」の切り口なら会員組織にも予算がつく。
- 「AI（ChatGPT・Claude・Dify）× LINE Bot」の依頼が増えている。AI の自動返信は月額サービスの付加価値になる。

**開けなかったところ**: クラウドワークスの検索ページ（3種類のURLとも表示できず。個別案件1件だけ開けた）、タイムチケット（403）。

### 事業への示唆（推測を含む）
1. **入口の価格**: 会員組織向けの月額サービスは、「構築3万円＋保守月1万円」より安く見えるか、ツール代込みで同じくらいに見える必要がある。目安は**月3,000〜10,000円**。
2. **受託より月額のツール**: 受託の構築は値崩れ。月額保守は単独では売れない。Lステップ・エルメのように「ツールとして月額で使ってもらう」。初期設定（3〜5万円）の入口は残すと乗り換えやすい。
3. **狙い目**: 案件数と予算があるのは医療・整骨院・歯科・美容の予約・会員証・リマインド。自分の強み（名簿・出欠・回覧・安否確認）が直接効くのは自治会・管理組合・教室・スポーツ団体・非営利だが、営業の経路は別に要る。
4. **AI 自動返信**を月額サービスの付加価値として付ける。

## 2. 教室・塾・スポーツクラブ向けサービスの料金

19サービスを調べ、17件は公式ページか公式アプリストアで数字を確認（ページの要約から読んだ値。資料に引用する前に原文を見直す）。
料金非公開: comiru・Grow・会費ペイ（決済手数料）・サブスクペイ for スクール・ミマム（31名以上）。
見つからなかったもの: スクールパートナー（ドメインなし）、ハピタス・Spoch（該当サービスを確認できず）。数字を確認できず外したもの: RESERVA（403）、SelectType（料金ページが空）。

**要点**
- 「**LINE で連絡＋名簿＋出欠＋月謝**」を全部公式にそろえるのは、確認した範囲では**コエテコマネージャーだけ**。ただし生徒1人あたり課金で、100人だと月1〜2万円。
- 教室管理系（できた！・wagaco・ミマム・comiru）は機能がそろうが、連絡は自社アプリ経由で LINE 連携をうたっていないものが大半（保護者にアプリを入れてもらう手間）。
- LINE 拡張系（Lステップ・エルメ）は LINE の連絡と名簿に強いが、振替・月謝の専用機能がなく、LINE公式の通数課金も別。
- 無料の連絡網（BAND・TeamHub・らくらく連絡網＋）は月謝・会費の集金と LINE がない。集金系（会費ペイ等）は連絡・出欠がない。
- **空白**: 「LINE で完結（保護者に新しいアプリ不要）」「振替の受付と月謝の自動引き落とし」「月額が定額で安い（〜3,000円）」を同時に満たすものがない。
  特に**スポーツ少年団・地域クラブ向けの「LINE＋会費集金」**はほぼ空いている（今は TeamHub / BAND＋現金・振込）。
- **狙い目**: 会員20〜100人の個人教室・少年団。**月1,000〜3,000円の定額（100人まで）＋決済手数料 2.5〜3.5% 前後**。
  通数課金を抑えるため、プッシュはまとめて送り、詳しい中身は LINE の中で開くページ（LIFF）で見せる。

比較サイトの数字は古いことがあるので、マンション軍師（5,600円 → 今は19,800円税別）とクラセル（2027年4月に値上げ）は公式の最新値に直した。「マンションノート」は口コミサイトで対象外。

**要点**
- **1戸あたり月額の相場**: 自治会系 0〜60円／管理組合ポータル 約60〜110円（**Mcloud の110円/戸が基準**）／会計込みの自主管理パッケージ 約450〜800円。
- 「LINE で受付 → 担当者に通知 → 記録」を安く出しているのは、賃貸の管理会社向けの **EPARK入居者Voice（月4,000円）だけ**。
- **分譲マンションの管理組合（特に自主管理）向けに、LINE で受け付けて対応状況を追えるものは見つからない**（大手管理会社の囲い込み用の POCKET HOME だけ。外部の組合は使えない）。
- **「未対応を再通知する」機能を書いているサービスは一つもない**。
- **空白**: ① 自主管理や小さな管理会社に任せている20〜100戸の分譲マンションで、LINE で受け付けて対応状況を追えるもの　② 管理100〜500戸の小さな管理会社・大家が、電気などのセット条件なしで使える「受付・再通知・記録」。
- **狙い目の値段**: 管理組合向け 1戸50〜100円/月（50戸で3,000〜5,000円。Mcloud の110円より下、まんくみの5,940円と同じくらい）。管理会社向け 月3,000〜10,000円の定額（EPARK 4,000円と いい生活Home 10,000円のあいだ）。総会の出欠・委任状（e投票は年3万円）もまとめれば、クラセル（450〜800円/戸）の手前の価格帯を取れそう。
- **気をつける点**: LINE公式の配信料（無料枠は月200通）が利益を削るので、通知の中心をチャットへの返信にする。自治体の無料提供（東京都の試用事業、結ネット・いちのいちの自治体負担）とも競合する。

## 4. 保護者向け「おたより AI」の競合

**要点**
- 「**保護者が取り込む → AI で予定・持ち物・締切を抽出 → 家族の LINE に届く**」を一気通貫でやる**商用サービスは確認できなかった**。近いもの（プリクリ・Papercal・TimeTree の予定スキャン）は、どれも**家族全員が専用アプリを入れる前提**。LINE を受け口と通知先にして、アプリなしで家族（祖父母も含む）に届けるところが空いている。
- **紙のおたよりは減っているが、整理の手間は残る**: お便りの配信が完全デジタルの学校は13.1%、半分以上48.6%、全くしていないのは5.1%（文科省、令和7年度）。大半は紙と配信の併用。PDF が「アプリの中に届くだけ」で、予定・持ち物の抽出と家族への共有は保護者の手作業のまま。
- 困りごとの声: 「子どもがプリントを渡し忘れる」が教員77%・保護者49%で1位、1つのツールへの統一を望む保護者89%（LINEヤフー調査 2024）。夫婦間の情報共有に困った56.1%（アドビ調査 2023）。
- **課金は厳しめ**: 国内の相場は月200〜400円（プリゼロ200円、プリクリPlus 400円、TimeTree 300円）。米国は月7〜10ドル。日本で個人課金だけで大きく伸ばすのは難しそう（推測）。道は、無料で使ってもらいつつ月300〜500円の家族プラン、または**自治会・PTA・習い事教室など配る側からもらう（B2B2C）**。
- **最大の脅威**: LINE カレンダー（2026年3月開始。今は画像からの抽出なし）が画像読み取りを足すこと。TimeTree の予定スキャンの拡張、Gemini・Apple・ChatGPT など OS・汎用 AI の標準機能。
- **空いている場面（推測）**: ① 保育園・幼稚園〜小学校低学年（持ち物が多い）② 習い事・学童・PTA・地域行事（学校の配信アプリの外）③ 兄弟で別の学校・園に通い配信アプリが複数ある家庭。**空いている機能**: LINE で受けて家族の LINE に配る、持ち物・提出物のチェックリスト化、前日・当日朝のまとめ通知、配信アプリの PDF・スクショの横断取り込み。
