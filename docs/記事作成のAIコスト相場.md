# 記事（イベントレポート）作成のAIコスト相場

2026-09-08 時点のメモ。関ヶ谷レポート第1号「納涼大会2026：あのやぐら、じつは脚立でできています」を
Claude Code（Claude Fable 5.1、定額サブスク）で書いた経験から、同じことを API でやった場合の相場をまとめる。
将来「アプリ内で AI に下書きさせる」機能（`docs/記事機能-設計.md` Phase 2）を作るときの見積もりに使う。

## 実測: 記事1本のトークン数

Anthropic の count_tokens API（無料）で計測。日本語はほぼ「1文字 ≒ 1トークン」。

| 対象 | 文字数 | トークン |
|---|---|---|
| 公開した記事本文（Markdown、写真URL含む） | 2,432 | 2,281 |
| 元原稿（`docs/articles/2026-08-納涼大会レポート.md`） | 3,144 | 3,106 |

## 概算: 「写真＋メモ → 記事1本」を API で生成した場合

前提: 写真6枚（1枚 約1,500トークン）＋箇条書きメモと指示文（約2,000トークン）を入力し、
本文 約2,500トークンを出力する。1回のリクエスト。

| モデル | 入力単価 / 出力単価（100万トークン） | 1回の生成 | 手直し5〜6往復込み |
|---|---|---|---|
| Claude Fable 5.1 | $10 / $50 | 約 ¥36 | ¥100〜200 |
| Claude Opus 5 | $5 / $25 | 約 ¥18 | ¥50〜100 |
| Claude Sonnet 5 | $2 / $10 | 約 ¥7 | ¥20〜40 |
| Claude Haiku 4.5 | $1 / $5 | 約 ¥4 | ¥10〜20 |

- 内訳（Fable の場合）: 写真 9,000トークン ≈ ¥14、メモ＋指示 2,000トークン ≈ ¥3、出力 2,500トークン ≈ ¥19。
- 写真を送らずメモだけで下書きさせると、入力が3分の1以下になる（Fable で 1回 ¥20 前後）。
- 1ドル150円換算。

## 補足

- Claude Code の対話で書く場合、毎回の応答で会話全体の文脈（ツール結果やコード）を送り直すため、
  実際の消費トークンは記事本体の数千トークンより桁違いに多い（1セッションで数百万トークン規模）。
  ただし定額サブスクなので追加費用は無い。
- 月に数本の記事なら、どのモデルでも金額は気にならない。品質重視なら Opus 5 か Fable、
  下書き用途なら Sonnet 5 で十分。
- カレンダー予定の PDF 抽出のコストは `docs/AIコスト・モデル方針.md` を参照
  （Gemini 無料枠で ¥0、Claude なら 1回 ¥8〜16）。
