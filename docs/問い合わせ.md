# 公式LINEのお問い合わせ（種類を選ぶ → 記録 → 担当者にメール）

公式LINEのチャットは件数が多く、担当者が少ないため問い合わせを見逃しやすい。問い合わせの種類を選んでもらい、
記録して担当者にメールで知らせ、未対応ならもう一度知らせることで対応漏れを防ぐ。

コードはこのリポジトリではなく、**名簿スプレッドシート（LINE_meibo）の GAS** にある（`Inquiry.js`、入口は `Main.js` の `doPost`）。
手元に取ってくるときは `scripts/gas/` に `clasp clone`（個人情報・トークンを含みうるので `.gitignore` 済み。コミットしない）。

## いまの仕組み（段階1・2026-10-11 作成、未反映）

1. リッチメニューの「お問い合わせ」ボタン（送る文 `お問い合わせ`）→ 種類のボタン（クイックリプライ）を返す。
   種類: 登録について知りたい ／ 班・戸番がわからない ／ 入力のしかたがわからない ／ その他（「問い合わせ担当」シートの行の順）
2. 種類を押す →「【問い合わせ：〇〇】」がトークに残る →「内容を書いて送ってください」と返す。
   - 名簿に未登録の人には、あわせて「お名前」「班と戸番」を書いてもらう。
   - 「班・戸番がわからない」は、登録済みかどうかに関係なく「お名前（フルネーム）」と「ご住所（例：5丁目25番18号）」を書いてもらう。苗字だけでは同居の家族や同じ苗字の家と見分けにくいので、住所と世帯の一覧を持つ事務局がフルネームと住所で確かめて調べる（自動の割り出しはしない）。
3. 次に届いた文を「問い合わせ」シートに記録（受付日時・LINE名・名簿の班-戸番と氏名・種類・内容・状態）し、担当者にメール。メールに本文を全文載せる。
4. 毎朝8時台（`remindInquiries`）: 24時間以上「未対応」のものを、担当者ごとに1通にまとめて全文で再通知。
5. 返事は LINE公式アカウント管理画面のチャットから。対応したらシートの「状態」を「対応済み」にする。

- 担当は「問い合わせ担当」シート（種類 → メール）。種類の行にメールがあればその人たち（例: 班・戸番 → 事務局）が宛先、「既定」の担当者2人が CC。空の種類は既定の2人が宛先。既定の2人は公式LINEで住民に返す役なので、どの種類も必ず受け取る。
- 事務局など公式LINEの管理者でない担当は、調べた結果をメールの「全員に返信」で既定の2人に返し、既定の2人が LINE のチャットで住民に返す（返信画面は段階3）。
- スクリプトプロパティ `INQUIRY_MODE`: `off`（既定・何もしない）／`test`（「リッチメニューテスト」シートの人だけ）／`live`。
- 種類を選んで 6時間 本文を送らなければ受付待ちは切れる（以後の文はふつうのチャット）。
- 返信（reply）は通数を使わない。通知はメールなので無料。

## 今後の計画

### 段階2: ボタンを使わない問い合わせも拾う
- 実際はいきなり文章を送る人が多い。バス時刻表などの自動応答に当たらないテキストをすべて「受信ログ」に記録し、毎朝のまとめに入れる。チャットで流れて見逃す問題の大半はこれで防ぐ。

### 段階3: 部署ごとの担当と、公式LINEの管理者でない人の返信画面
- **部署で分ける**: 事務局・会計・防災・会長など、種類ごとに部署（担当者のメール）を割り振る。担当者は公式LINEの管理者でなくてよい。
- **返信画面**: メールの「この問い合わせに返信する」リンク（その問い合わせ専用の鍵付きリンク・期限 14日程度）から開く。GAS の同じ Web アプリ（`doGet`）で作る。
  - 問い合わせの内容、送った人（名簿の氏名・班-戸番）、これまでのやりとりを表示。
  - 返信を送ると相手の LINE にプッシュメッセージで届き（1回1通を使う）、自動で「対応済み」になる。シートに「誰が・いつ・何と返したか」を残す。担当者はシートに触らなくてよい。
  - 「返信せずに対応済みにする」ボタン（電話・対面で対応した場合）。
  - 返信画面から送ったメッセージは LINE公式アカウント管理画面のチャットに出ない可能性があるので、やりとりは必ずシートに残す。
  - 鍵付きリンクはメールを転送されると転送先も返信できる。期限で危険を小さくする。
- **引き上げ（エスカレーション）**: 一定時間（例 48時間）未対応なら事務局・会長にも知らせる。
- **毎朝のまとめ**: 未対応の一覧を管理者全員に1通で送り、誰か1人が気づけば拾えるようにする。

### 決めること（段階3の前に）
- 部署の分け方と各部署の担当者（メールはシートに書く）
- 引き上げ先（事務局? 会長?）と時間

### できないこと
- 過去のチャット履歴は Messaging API で取り出せない。導入前に見逃した分は、LINE公式アカウント管理画面のチャットで「要対応」の絞り込みを使って洗い出す。
