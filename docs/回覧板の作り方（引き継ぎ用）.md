# 毎月の回覧板の作り方（引き継ぎ用・1 枚）

管理画面: https://sekigayajichikai.vercel.app/admin （PC の Chrome で開く）
パスワード: 前任の管理担当から受け取る（この紙には書かない）
確認担当: ＿＿＿＿＿＿ さん（LINE で確認リンクを送る相手）

管理画面の右上「使い方」を押すと、この手順が画面でも読めます。

## 毎月やること（この順に）

1. **ログインする**
   管理画面を開いてパスワードを入れる。
2. **「今月の流れ」のボタンを押す**
   回覧板タブの一番上に、今やることと青いボタンが出ている。迷ったらそのボタン。
3. **PDFを追加する**
   「自治会のお知らせ」＝関ヶ谷だより・会報などの回覧板 PDF。AI が記事に分ける（1〜3 分待つ）。
   「地域のお知らせ」＝学校だより・チラシ。PDF のまま載る。複数まとめて選べる。
   途中で「PDF情報を入力」が出たら、題名と号数を確かめて「確定して記事を抽出」。
4. **記事を見て直す**
   題名や文を直すときは記事を開いて「編集」。いらない記事は「削除」。
   間違えて消しても右上「ゴミ箱」から戻せる。
5. **「確認を依頼」を押して、リンクを担当者に送る**
   回覧板を開くと右上に「確認を依頼」がある。押すとリンクが出るので「LINEで送る」。
6. **「承認済み」が付いたら「公開する」**
   担当の方が承認すると、回覧板タブに「承認済み」の印が付き、右上のボタンが「公開する」に変わる。
   押せば住民のページに出る。公開後に直したいときは「その場で直す」。

## 困ったとき

| こうなったら | こうする |
|---|---|
| 「AI の読み取りと LINE 配信の準備ができていません」と黄色く出る | 右上「ログアウト」→ もう一度ログイン。消えなければ管理担当に連絡 |
| PDF を選んでも入らない | 10MB より大きい PDF は入らない。小さくするか、ページを分ける |
| 間違えて消した | 右上「ゴミ箱」→「元に戻す」。回覧板・記事・予定が戻せる |
| 「公開する」が見当たらない | まだ承認されていない。右上は「確認を依頼」か「確認リンクを表示」になっているはず |
| 同じ月の回覧板を 2 つ作ってしまった | いらない方を開いて「削除」。ゴミ箱から戻せるので慌てなくてよい |

## やらなくてよいこと

- 「関ヶ谷レポート」「週次配信」「リッチメニュー」「予定」「マスタ」のタブは、回覧板を出すだけなら触らなくてよい。
- 「PDFの切り抜き」「サムネイル生成」は見栄えを良くする追加作業。なくても公開できる。
