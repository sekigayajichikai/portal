# 画面の用語集（2026-10-06 決定）

portal（回覧板）と book-system（カレンダー・会館予約）の**画面に出る言葉**をそろえるための表。
新しく画面の文言を書くときも、この表に合わせる。コードの名前（`Newsletter`、`EventCard` など）は変えない。
（UI評価・改善計画.md の B6）

## 呼び名

| 対象 | 使う言葉 | 使わない言葉 | 備考 |
|---|---|---|---|
| 回覧板（全体・1回分） | **回覧板** | 電子回覧板、号（単独）、電子回覧板の号 | 1回分の名前（タイトル）は「2026年10月号」のまま。確認文などは名前を入れる（「2026年10月号」を公開しますか？）。号が分からないものは「回覧板なし」 |
| 紙面の通し番号 | 号数 | — | PDFに印刷された「第123号」のこと。回覧板の呼び名とは別 |
| 予定 | **予定** | イベント、イベントカード、予定カード、カード、行事、催し | 種類を分けるときは「予定（回覧板）」「予定（カレンダー）」 |
| 回覧板の記事 | **記事** | — | |
| 関ヶ谷レポート | タブ・見出しは「**関ヶ谷レポート**」、1件は「**レポート**」 | レポートの1件を「記事」と呼ぶこと | 「イベントレポート」は分類名なのでそのまま |
| 会館の予約 | **予約** | 申請、申し込み（名詞）、予約リクエスト | 管理画面のタブは「**承認待ちの予約**」。動詞の「申し込む」は使ってよい |
| 予定への参加の申込 | 申込（申込締切 など） | — | 会館の予約とは別 |
| 取り込み | **取り込み**／取り込む | 取込、取込み、インポート | |
| マスタ | **マスタ** | マスター | |
| 場所の一覧 | **会場**（会場マスタ） | 場所マスタ、実施場所 | 入力欄のラベルは「場所」でもよい |
| 団体 | マスタの名前は「**団体**」 | 主催団体（マスタ名として） | 役割としての「主催」「発行元」はそのまま使う |

## 状態

| 対象 | 使う言葉 | 使わない言葉 |
|---|---|---|
| 公開の状態 | **下書き／確認待ち／修正依頼あり／公開中／非公開** | 公開済み、一般公開、掲載 |
| 確認の流れ | **確認リンク**、**修正依頼**（「修正依頼を送る」） | 確認用リンク、修正をお願いする |

| 使う | 使わない | 備考 |
|---|---|---|
| 削除 | 消す（ボタン・確認文） | 説明文の中の「消えます」はよい |
| キャンセル（ダイアログを閉じる） | 取消 | |
| 取り消す（したことを元に戻す） | 取消 | |
| 編集 | 修正（ボタン名として） | 「修正依頼」は別の言葉なのでそのまま |
| タイトル | 題名 | |
| 紐づけ | 紐付け | |
| 並べ替え | 並び替え | |
| 切り抜き | クロップ、切り出し | |
| …（読み込み中… など） | ...（ピリオド3つ） | |

## 開発者向けの言葉を出さない

| 今 | 直し方 |
|---|---|
| Gemini／Claude とモデル名 | 「**AI**」。どのAIかは画面に出さない |
| `sql/migrations/...`、DBの列、`.env.local`、Supabase の Secrets、環境変数名、「API error」 | 「**設定が足りません。管理者に連絡してください**」など。中身は `console.error` に残す |
| エイリアスID | **メニューの識別名** |
| カスタムタイトル | **表示するタイトル** |
| Flex JSON をコピー | 「開発者向け」の折りたたみの中に入れる |
