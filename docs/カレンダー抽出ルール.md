# カレンダー（イベント予定）抽出ルール

回覧板の記事・PDFから、カレンダーに載せるイベント予定（event_cards）をAIで抽出する際のルール。
実装: `packages/shared/services/ai/claudeService.ts`（`extractEventCandidates` / `extractEventCandidatesFromPDF`）、
UI: `apps/circulars/src/components/admin/EventCandidateDialog.tsx`。

## 抽出対象
- **記事テキスト**（記事化された号の記事）と、**添付PDF**（source=自治会のお知らせ / attachment=地域のお知らせ）の**両方**から抽出する。
- 同一イベント（同じ `event_date` + `title`）は重複除去し、記事由来を優先して残す（記事にリンクできるため）。

## 日付・イベントの扱い
- **開催日が特定できるものだけ**抽出（「毎週」「随時」「未定」は除外）。
- 年が書かれていない日付は、回覧板の**発行日以降で最も近い日付**として解釈する（発行日=issue_date は「年の推定」に使う）。
- 行事予定表のように日付が羅列されている場合も1件ずつ抽出する。
- **過去の報告記事（開催済みの報告）は除外**する。
- **過去の予定は抽出しない**: 基準は「**抽出した日（今日）**」。今日より前の日付の予定は候補に出さない（同日は含む）。AIプロンプトでの指示に加え、ダイアログ側でも今日より前を弾く二重ガード。
  - 発行日ではなく「今日」基準にした理由: 過去号をまとめて入力するときも終了済みを自動除外できるため。
- **公開カレンダー表示**でも「今日より前の予定」は非表示（`CalendarView`）。抽出基準に関わらず住民には過去予定が出ない。

## 募集・締切ルール（重要）
- 「募集」「申込」「〆切/締切」などの**締切系の日付は、自治会関連の記事・PDFからのみ抽出**する。
  - 記事: `article_type === 'official'`（自治会のお知らせ）＝自治会関連。
  - PDF: `type === 'source'`（自治会のお知らせ）＝自治会関連。`type` 未設定の旧データは自治会扱い。
- **自治会以外の発行元**（地域のお知らせ＝`local-info` / PDF `attachment`。例: 学校だより、駐在所、にしかぜ 等）からは、
  **募集・申込・締切は予定として抽出しない**。実際に開催されるイベントの**開催日のみ**抽出する。

## イベント種別（category）
イベントの性質ごとにカレンダーの見せ方を変えるため、`event_cards.category` を持つ。AI推定＋抽出ダイアログで手直し。
- `reserve`（要予約）… 予約・事前申込が必要。対象が限られる（地区センター講座 等）。カレンダーで「📝要予約」バッジ。公開カレンダーに「要予約の催しを隠す」フィルタ（既定OFF＝集客のため全表示）。
- `recurring`（連続）… 毎週・定期・全N回（習い事・体操教室・連続講座）。**日ごとに分けず1件に集約**し、次回開催日＋「毎週◯曜」で表す（カード氾濫防止）。「🔁毎週・連続」バッジ。
- `open`（当日参加OK）… 申込不要で当日自由参加（お祭り・サロン）。集客したいので目立たせる（「🎪当日参加OK」バッジ＋色）。
- `null`（一般）… 特に指定なし。

※Phase1は単一種別タグ。連続イベントの本格的な繰り返しルール（毎週◯曜・終了日での自動展開）はPhase2の検討事項。要予約かつ連続（習い事）のような重なりは、より重要な方の種別を選ぶ。

## 主催団体（organizer）
- 主催団体は事前に**マスター登録**（管理画面「主催団体」）しておく。
- 抽出時、登録済みの主催団体名をAIに渡し、**表記を登録名に寄せる**（表記揺れの低減）。
- 抽出ダイアログでは、抽出結果をグレーのタグで表示。クリックで検索付きピッカー（Notion風）を開いて選び直し・新規登録が可能。

## 出典リンク
- 各イベントは**由来PDF**（`event_cards.source_pdf_url`）を記録し、カレンダーの「元のPDFを見る」はその**実際の抽出元PDF**へリンクする（号の先頭PDF固定をやめた）。
- 記事にリンクできる場合は「記事を読む」を優先表示、無ければ由来PDFへのリンクを表示する。

## 関連DBカラム（iplc / sekigaya-portal）
- `event_cards.organizer TEXT` … 主催団体
- `event_cards.source_pdf_url TEXT` … 由来PDFのURL
- `organizers` テーブル … 主催団体マスター
