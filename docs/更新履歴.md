# 更新履歴

使う人から見て「何が変わったか」を、アプリの更新履歴のように新しい順で残す。
仕組みや理由の詳しいことは、各項目のリンク先の文書に書く。

書き方: 日付ごとに「新しく」「よくなった」「なおした」に分けて1行ずつ。誰に向けた変更か（住民・管理者）がわかるように書く。

---

## 2026-10-27

### ポータル（管理者向け）
**新しく**
- Drive の自動取り込みが、月フォルダの中の `pic` フォルダの写真（jpg / png / webp）も読むようになりました。写真はその月の下書きの号の「保留画像」に入るだけで、どの記事に付けるかは人が決めます。号の画面に「📷 Drive の写真を記事に付ける（N枚）」ボタンが出るので、押して記事を選んでください（切り抜きもできます）。その月の号がまだ無いときは取り込まず、朝のメールに「写真はあとで」と出ます。→ `scripts/drive-import/README.md`

**なおした**
- 「確認を依頼」の確認用リンクや週次配信のリンクが、管理画面を Vercel のデプロイごとのアドレス（portal-xxxx-hanainc.vercel.app）で開いていると、そのアドレスで作られ、受け取った人が Vercel へのログインを求められていたのをなおしました。そういうアドレスで開いていても、リンクは本番（sekigayajichikai.vercel.app）で作ります。

**よくなった**
- 週次配信の「配信の曜日」「配信日」を、題名の右端から、題名のすぐ下の独立した行（灰色の帯）に移して大きくしました。画面の幅によって説明文の下に回り込み、見つけにくくなっていたためです。
- 号の画面の「今後の予定」「記事一覧」「登録済みPDF」の畳む／開くを、右端の小さなボタンから、見出しの左の大きな「＞／∨」マークに変えました。見出しごと押せます。畳んでいる間はマークが青になり、「畳んでいます（押すと開く）」を見出しと同じ濃さ・大きさで出します。

## 2026-10-26

### ポータル（管理者向け）
**なおした**
- 予定の抽出で、同じ予定が記事とチラシ（PDF）の両方に載っているとき、「記事にリンク」だけになってチラシの方が捨てられていたのをなおしました。候補にチラシの名前も出て、登録すると由来PDF（チラシ）も付きます。登録済みの予定で由来PDFが空なら、もう一度抽出して登録すると補完されます。
- 号の「登録済みPDF」で、「PDF版で読む」と「回覧板PDF」が混ざっている号だと、「上へ」「下へ」で別のPDFが動いたり、種類のタグ（青／緑）が隣のPDFのものになったりしていたのをなおしました。表示は種類ごとにまとめているのに、動かす番号は元の並びを見ていたのが原因です。「上へ」「下へ」は同じ種類の中だけで動きます。

**よくなった**
- 週次配信の一押しカードの切り抜きに「✨ AIで記事の場所を探す」ボタンを付けました。回覧板のページの中からその予定の記事をAIが探して、切り抜きの位置と大きさをそこに合わせます。提案なので、プレビューで確かめて直してから「切り抜きを保存」してください。予定の編集画面の切り抜きにも同じボタンがあります。
- 管理画面のタブの並びを、毎月の作業の順（回覧板 → 予定 → 週次配信 → リッチメニュー → 関ヶ谷レポート → マスタ）にしました。
- 号の画面で「AIで抽出」から予定を取り込んだあと、「予定タブで重複や日時を確認してください」の案内を出すようにしました（「予定タブを開く」ボタン付き）。
- 「PDFの切り抜き」「画像の切り抜き」の画面で、切り抜き枠の形（自由／正方形／横長 4:3／横長 16:9／縦長 3:4）を選べるようにしました。形を選ぶと枠がその比率に固定され、記事の写真を同じ形でそろえられます。
- 週次配信の画面に（予定タブや号の画面から）戻ってきたとき、予定を裏で読み直すようにしました。他の画面で由来PDFや記事リンクを付けたのに週次配信では「チラシも記事も無い」と出る、ということがなくなります。
- 週次配信の一押しを最大5件まで選べるようにしました（今までは2件）。カードには選んだ順に縦に並びます。
- 週次配信の一押しが2件以上あるとき、▲▼で順番を入れ替えられるようにしました（今まではチェックを付け直すしかありませんでした）。1番目がカードの上に出ます。
- 週次配信の文字を全体に大きく、薄い灰色を濃くしました。LINE に届くカードの主催・場所・締切の行も本文と同じ大きさ・濃い色にしたので、読みやすくなります（住民向け）。管理画面の週次配信タブも同じく一段大きくしました。
- 週次配信で、まだ公開していない号（下書き）に入れた予定も候補に出るようにしました。画面では「◯月号・未公開」の印が付きます。公開前の号の記事には住民が飛べないので、そういう予定はチラシPDFにつなぎ、チラシも無ければリンク無しで載ります。
- 週次配信で「配信の曜日」を選べるようにしました。選ぶと配信日が直近のその曜日になり、配信予定の表もその曜日で並びます。次に開いたときも覚えています。
- 号を開いたときの「今後の予定」「記事一覧」「登録済みPDF」のそれぞれに「畳む／開く」ボタンを付けました。記事が多い号でも、畳めば下の欄にすぐ行けます。畳んだかどうかはブラウザが覚えます。ボタンは大きめ・濃いめで、畳んでいる間は青くして気づけるようにしました。
- 週次配信の下書きを「配信日1つにつき1つ」にして、プルダウンの代わりに画面上部に「配信予定」の表を置きました。今週から5週先まで、配信日ごとに「下書きを作ったか」「予約したか・送ったか」が1行ずつ見えるので、1か月分をまとめて予約するときに抜けている週がすぐ分かります。行の「開く」「この週を作る」でその配信日に移ります。→ `週次配信.md`
- 週次配信の「LINE に送る」の吹き出し①の文は直すと自動で下書きに保存されますが、保存ボタンが無く保存されたか分かりにくかったので、入力欄のそばに「下書きに保存済み（時刻）」を出すようにしました。ラベルも「直すと下書きに自動保存」に変えました。

**新しく**
- Google Drive の「回覧板Data」の月フォルダに置かれた「関ヶ谷だより」「会報ふれあい」の PDF を、毎朝7時に自動で取り込んで、その月の号（下書き）に PDF と記事を作る仕組みを入れました。公開は今まで通り人が行います。結果は sekigaya.dx@gmail.com にメールで届き、管理画面の「今月の流れ」にも「Drive から自動で取り込んだ記事を確認」と出ます。→ `Drive取り込み-計画.md`、`scripts/drive-import/README.md`
- 回覧板の「PDFを追加」で、PDF のほかに写真（JPG・PNG・WebP）も選べるようになりました。選んだ写真はその場で PDF に変換して、今まで通り PDF として登録します（自治会のお知らせで複数枚選ぶと1枚＝1ページ、地域のお知らせでは1枚＝1件）。スマホ写真は向きを直し、長辺2000pxに縮めてから登録します。→ `回覧板の作り方（引き継ぎ用）.md`
- 回覧板の「PDFから記事抽出・画像追加」の画像モードに「4コマ漫画の記事として保存」ボタンを置きました。関ヶ谷だよりの4コマ漫画の範囲を選んで押すだけで、題名「釜利谷駐在所４コマ漫画　画：しばやまよしの」の本文なし・画像だけの記事ができます（その号に同じ題名の記事があれば、そこに画像を足します）。題名を変えたいときは `ArticleCropPage.tsx` の `COMIC_PRESET` を直します。
- 週次配信の一押しカードに載せる画像の元を、チラシ（PDF）／記事の写真／回覧板の先頭PDF から選べるようになりました。いままでは「詳しく見る」のリンク先を記事にしても画像はチラシのままでしたが、画像だけ記事の写真に切り替えられます。選んだ元は切り抜きと一緒に予定カードに保存され、次の週も同じになります。予定の編集画面にも同じ欄があります。→ `週次配信.md`

### 公式LINE
**準備中**
- 隣の自治会の方向けに、バス停「夏山坂上」（中学校前の隣）の時刻表を京急バスの公式時刻表から用意しました。公開はまだで、停留所選びには出していません。

**よくなった**
- バス時刻表の返事がとても速くなりました（約2〜6秒 → 1秒以内）。全員に広げました（保存してあった46人・55件の行き方もそのまま使えます）。→ `バス時刻表.md`
- 公式LINEに届くメッセージが本物のLINEからのものか確かめるようになり、なりすましの通知を受け付けなくなりました。
- バス時刻表で「平日ダイヤを見る」など別のダイヤを見たとき、「次は 10月13日（火）」と、そのダイヤで次に走る日が出るようになりました。
- 夜中（0時〜4時台）に時刻表を開くと、「今朝 10月13日（火）」「始発」と出るようになりました。寝る前に明日の朝のバスを調べるときに、日付を取り違えにくくなります。
- バスまでの待ち時間が「あと 392分」ではなく「あと 6時間32分」のように出るようになりました。

**なおした**
- 土休日ダイヤで、実際には走っていない「野村住宅センター 21:44 発」（西小学校前 21:45・中学校前 21:46）の便を案内していたのをなおしました。
- 毎週の時刻表の自動チェックが、実際には公式の時刻表を読めておらず、平日の2か所しか比べていなかったのをなおしました。いまは選べるバス停すべてを、平日・土休日とも比べます。
- 祝日ではない日（クリスマス・大晦日・節分・雛祭り・七夕など）を、バスの土休日ダイヤとして表示していたのをなおしました。祝日は国（内閣府）の祝日一覧で判定します。
- 日曜日などに「平日ダイヤを見る」を押すと「【平日ダイヤ】10月11日（日）」と、今日が平日ダイヤであるかのように出ていたのをなおしました。
